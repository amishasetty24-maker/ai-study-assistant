\## ⚙️ How It Works



\### Text Summarization

\- User enters text.

\- Frontend sends the text to the Flask backend.

\- Backend processes the text and returns a summary.



\### PDF Summarization

\- User uploads a PDF file.

\- Backend extracts text using PyPDF2.

\- Summary is generated and returned to the user.
